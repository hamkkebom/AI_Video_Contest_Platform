# IA — 정보구조 설계 (2026-08-01)

> **마지막 갱신**: 2026-08-01
> **배경**: 2026-08-01 UX 감사에서 "미로 구조"의 원인이 확인됨 — 고아 페이지 7종, 대시보드 진입 시 글로벌 헤더 소멸, 갤러리 상세 로그인 벽, 공모전 기본 필터의 빈 화면, 준비중 메뉴 노출. 이 문서는 그 해소를 위한 정보구조 단일 기준이다.
> **유지 규칙**: 라우트를 추가·이동·삭제하거나 내비/접근 정책을 바꾸는 변경은 이 문서를 같은 커밋에서 갱신한다. 결정 배경은 [DECISIONS.md](DECISIONS.md) D-013 참조.

## 1. IA 원칙

1. **공개 가치는 연다** — 콘텐츠 감상(갤러리·수상작)은 비로그인 공개. 로그인은 "행위"(출품·좋아요·문의 이력)에만 요구한다.
2. **존재하는 페이지는 지도에 있다** — 내비(헤더/푸터/사이드바) 어디에서도 도달할 수 없는 페이지를 만들지 않는다. 미완성 페이지는 내비와 sitemap 양쪽에서 뺀다 (한쪽만 빼지 않는다).
3. **세계를 쪼개지 않는다** — 대시보드에서도 글로벌 헤더를 유지한다. 공개 영역 ↔ 대시보드 이동에 멘탈 모델 리셋이 없어야 한다.
4. **첫 클릭은 빈 화면이 아니다** — 기본 필터·기본 탭은 콘텐츠가 있는 쪽을 자동 선택한다. 빈 상태 카피는 콘텐츠가 있는 곳으로 안내한다.
5. **장치보다 안내** — 컨트롤(필터·토글·설정)은 콘텐츠 볼륨이 정당화할 때만 추가한다.
6. **없는 것은 404로 답한다** — 존재하지 않는 상세 페이지는 커스텀 안내 UI를 200으로 렌더하지 않고 `notFound()`를 호출한다. 상세 라우트에는 `loading.tsx`를 두지 않는다(스트리밍이 시작되면 상태코드를 바꿀 수 없다). `try/catch` 안에서는 `unstable_rethrow`로 Next 제어 예외를 통과시킨다.

## 1-1. 디자인 토큰 (2026-08-01 신설)

색은 `app/globals.css`가 단일 소스다. 컴포넌트에서 원시 팔레트(`bg-orange-500`)나 임의값(`bg-[#EA580C]`)을 쓰면 테마가 그 화면에 닿지 못한다.

| 토큰 | 용도 |
|---|---|
| `--brand` / `--brand-hover` / `--brand-foreground` | AI꿈 시그니처 오렌지. CTA·강조 |
| `--primary` | 테마별 주색 (signature=브랜드 오렌지, light/dark=violet) |
| `--status-{draft,open,closed,judging,completed}` | 공모전 상태 5종. 라벨은 `config/constants.ts`, 색은 여기 |

- 상태 뱃지는 `<ContestStatusBadge>` 하나만 쓴다 (solid/soft/overlay).
- 테마는 3종이 실제로 구분되어야 한다 — 예전엔 signature가 light와 같은 블록이라 골라도 변화가 없었다.
- 관리자 화면의 카테고리 색(아티클 유형, 수상 티어)은 브랜드가 아니라 분류 표시이므로 원시 팔레트를 허용한다.

## 3. 내비게이션 모델

### 3.1 글로벌 헤더 (모든 페이지 — 대시보드 포함)

| 슬롯 | 내용 |
|---|---|
| 좌 | 로고 (→ `/`) |
| 중앙 메뉴 | **공모전** `/contests` · **갤러리** `/gallery/all` · **수상작** `/gallery/awards` · **스토리** `/story` |
| 우측 | 검색 아이콘 (→ `/search`) · 대시보드 버튼(역할별) · 아바타 드롭다운 |

- 헤더 메뉴 링크에 쿼리 파라미터를 넣지 않는다 (`/contests?status=open` 금지 — 기본 탭은 목록 페이지가 결정).
- **대시보드 버튼**: 보유 역할이 2개 이상이면 드롭다운(보유 역할의 대시보드만 나열 — 참가자 대시보드는 로그인 유저 공통 포함), 1개면 바로 이동. admin은 4종 전체 노출 유지. "관리자 대시보드"와 `/admin` 루트는 `/admin/dashboard`로 — 조사 결과 대시보드 페이지는 실구현 상태였다(관리자 홈은 한 곳).
- 대시보드 라우트에서도 헤더를 렌더한다. 사이드바는 헤더 아래(top-16)에서 시작한다.
- `menu.gallery`/`menu.story` 사이트 설정 토글은 유지하되, 끌 경우 sitemap에서도 함께 빠져야 한다(고아 방지 — 구현 시점에 확인).
- 헤더의 `HoverDropdown`/`children` 메뉴 지원은 사용처가 없으므로 삭제한다.

### 3.2 글로벌 푸터

| 컬럼 | 링크 |
|---|---|
| 브랜드 | 함께봄 (외부) |
| 서비스 | 공모전 · 갤러리 · 수상작 · 크리에이터 · 스토리 |
| 지원 | FAQ · 문의하기 · 제작 대행 의뢰 |
| 안내 | 이용약관 · 개인정보처리방침 |

- 주석 처리된 TODO 링크는 전부 복원 또는 삭제한다. 주석으로 남기지 않는다.

### 3.3 대시보드 사이드바

- 공통: 상단 로고/"서비스 홈" 중복 제거(헤더가 유지되므로 사이드바는 메뉴 목록과 계정 정보만).
- **admin**: 과업 단위 5섹션 — 운영 현황(대시보드·분석) / 공모전(관리·제출물·수동 등록·영상) / 회원·문의(회원·기업·문의·대행 의뢰) / 콘텐츠(아티클·팝업) / 설정(사이트 설정·가격 설정(동결)·프로필). "준비중" 라벨 6개는 조사 결과 전부 실구현 페이지(문의·대행은 D-011로 검증)로 확인돼 폐기했고, 가격 설정만 수익화 동결(D-005) 표기를 유지한다.
- **my/judging**: 항목이 1~2개뿐이므로 별도 세계 유지의 근거가 없음 — 라우트 통폐합(탭화)은 이번 범위에서 제외하고 로드맵 후보로 기록(§6). 이번에는 헤더 유지로 단절만 해소.

## 6. 이번 범위에서 제외 (로드맵 후보로 기록)

- **대시보드 라우트 통폐합**: `/my`·`/judging`을 탭 구조로 합치는 리팩터링 (라우트 변경 + 리다이렉트 필요)
- **익명 조회수 점수 정책**: 갤러리 공개 전환 이후, `online_vote_type`에 views가 포함된 공모전은 인증 조회만 집계하거나 별도 컬럼 분리 검토
- **landing/상세 canonical 정리**: SEO 중복 해소 (canonical 태그 조정 또는 랜딩의 공모전별 분리)
- **pricing 가짜 가격 폴백 제거**: 수익화 재개(D-005 트리거) 시점에 처리
- **제출 메가폼(1,765줄) 단계 분리**, **관리자 공모전 폼(2,196줄) 분해**
